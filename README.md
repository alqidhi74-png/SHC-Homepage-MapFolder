# Sultan Haitham City — Cinematic Homepage

نسخة معدلة من نفس المشروع الحالي، بدون إعادة بناء الهيكل.

## التجربة

- افتتاحية يتحرك شعارها مع التمرير حتى يستقر في الهيدر.
- خريطة تفاعلية تعرض مرافق المدينة ومؤشرات المخطط العام في مشهد واحد.
- بطاقات مرتبطة مباشرة بمواقع الأحياء والخدمات على الخريطة.
- مسارات مباشرة للخريطة والمشاريع والخدمات الإلكترونية.

## التشغيل
```bash
npm install
npm run dev
```

## حساب الأدمن التجريبي

- صفحة الدخول: `/login`
- البريد المستخدم للدخول: `israa.alwahaibi@shc.gov.om`
- كلمة المرور: `admin@190`
- بعد الدخول الصحيح تظهر رسالة نجاح في نفس صفحة الدخول لاختبار الحساب فقط. لا توجد صفحة داشبورد جديدة ولا تحويل تلقائي حاليًا.
- الجلسة العادية تستمر في التبويب الحالي حتى 8 ساعات. «تذكرني» يحفظها في المتصفح لمدة 7 أيام. تسجيل الخروج يمسحها.

هذه مصادقة تجريبية داخل المتصفح. بيانات الدخول مضمنة في الواجهة. قبل ربط بيانات الإدارة الحقيقية، يجب استبدال `src/auth/demoAdminAuth.js` بمصادقة من الخادم والتحقق من الصلاحيات على الخادم. لا تُحفظ كلمة المرور في تخزين المتصفح.

عند إضافة الداشبورد الجاهزة لاحقًا، أضف مسارها ثم وجّه إليه بعد نجاح الدخول في `src/components/Login/LoginPage.jsx`. البريد أعلاه اسم دخول تجريبي وليس صندوق بريد منشأ.

تشغيل فحوص حساب التجربة:

```bash
npm run test:auth
```
